Corso Shield 2.2.0 adds daily app-update checks and a Check for app updates button using Sparkle 2.10.1 and GitHub Releases. Update archives and the feed are signed with Ed25519; the public key is pinned in the app. Installation asks for confirmation. The background scanning service is paused during installation and resumed on application relaunch.

Includes the existing ClamAV scans/signature updates, download monitoring, reviewed quarantine/restore, and rootkit/reverse-shell indicator checks. These are supplemental user-space checks, not proof of a clean system or full kernel protection.

Universal macOS 13+ development build (Apple Silicon and Intel). Install ClamAV separately. This release is ad-hoc signed and is not Apple notarized. Full Disk Access may need to be reapproved after replacing an ad-hoc signed app. Virus signatures continue to come from FreshClam; the app updater does not update the ClamAV engine.
