Corso Shield 2.3.0 adds reviewed bulk removal of ClamAV detections into restorable quarantine. Each file's digest is rechecked, modified files are refused and partial failures are recorded. This does not promise removal of running malware, rootkits or every persistence component.

Settings recovery supports DNS and HTTP proxy values for one Mac network service using a user-approved trusted snapshot, Keychain authentication, same-device binding, a change preview, pre-change backup and read-back/rollback. No real network settings are changed merely by installing or opening the app. Administrative authorization may still be required.

The source also includes a first runnable Windows PowerShell companion beta: Defender scans and remediation, daily Defender scan configuration, DPAPI-protected settings baselines and previewed recovery of allowlisted protection/firewall/proxy settings. Windows live remediation and GUI device acceptance tests remain required; there is no Windows custom service or automatic app updater yet.

Development build, ad-hoc signed and not Apple notarized. Existing Full Disk Access may need reapproval after replacing this build. No threat removal or settings recovery is enabled automatically.

Permission setup now runs for each changed Mac executable/location before background scans can resume. It guides owner-approved Full Disk Access and optional recovery Keychain preparation and reports limited coverage explicitly. Windows beta 0.2 adds a Program Files script installer, protected install ACLs, same-user UAC launcher and startup prerequisite checks. OS approvals remain explicit; installer approval cannot permanently grant administrator/network-recovery permissions.
